# 🛠️ Image To Code Skill (Skill Agnóstica Universal)

## Visión General
Skill agnóstica universal parametrizada para ejecutar tareas de Image To Code Skill en cualquier proyecto, arquitectura o repositorio.

## ⚡ Flujo de Ejecución

```bash
python scripts/run_image_to_code_skill.py --project "CualquierProyecto" --input "./data"
```
