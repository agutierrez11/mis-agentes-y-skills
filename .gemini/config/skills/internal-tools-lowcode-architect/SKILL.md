# Skill: Internal Tools & Low-Code Architect

## Propósito
Diseñar y construir aplicaciones internas, paneles de control (dashboards), consolas de administración para RevOps y conectores de múltiples bases de datos (PostgreSQL, MongoDB, APIs REST) con una estética UI premium y rápida velocidad de desarrollo.

## Arquitectura de Aplicaciones Internas
1. **Conectores Multifuente:**
   - Integración rápida con bases de datos relacionales, buckets S3 y servicios de autenticación corporativos.
2. **Componentes Reutilizables de Administración:**
   - Tablas de datos con filtrado dinámico, modales de edición, exportación a CSV/JSON y dashboards de KPIs comerciales.
3. **Despliegue y Autohospedaje:**
   - Patrones para ejecutar aplicaciones de administración en contenedores Docker de forma segura dentro de la infraestructura del cliente.
