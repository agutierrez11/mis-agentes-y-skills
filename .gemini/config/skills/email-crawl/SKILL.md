# 🛠️ Email Crawl (Skill Agnóstica Universal)

## Visión General
Skill agnóstica universal parametrizada para rastrear páginas web, extraer direcciones de correo electrónico corporativo y de contacto en cualquier proyecto o dominio objetivo.

## ⚡ Flujo de Ejecución

```bash
python C:\Users\Antonio\.gemini\config\skills\email-crawl\scripts\run_email_crawl.py --url "https://ejemplo.com" --depth 2 --max-pages 15
```

## 📋 Parámetros
* `--url`: URL objetivo a inspeccionar.
* `--depth`: Profundidad de navegación en enlaces internos.
* `--max-pages`: Límite máximo de páginas web a escanear.
