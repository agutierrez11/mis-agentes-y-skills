# Skill: Modular, Mojo & MAX AI Engine

## Propósito
Optimizar el rendimiento de ejecución de modelos de IA y aceleración de cómputo en CPU/GPU utilizando el lenguaje **Mojo** (sintaxis Python con velocidad C/C++) y el motor **MAX Engine** de Modular para inferencia de baja latencia.

## Capacidades Principales
1. **Compilación y High-Performance AI:**
   - Escribir e integrar módulos en Mojo para tareas intensivas en cómputo (vectorización, operaciones matriciales, procesamiento de imágenes/audio).
2. **MAX Engine Inference:**
   - Servir modelos de lenguaje y visión con baja latencia y alta concurrencia mediante el runtime acelerado de MAX Engine.
3. **Migración e Interop Python-Mojo:**
   - Integrar bibliotecas estándar de Python dentro de pipelines optimizados en Mojo sin sobrecostos de serialización.
