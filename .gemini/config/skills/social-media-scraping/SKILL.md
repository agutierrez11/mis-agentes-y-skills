# 📱 Social Media Scraping (Skill Agnóstica Universal)

## Visión General
Skill agnóstica universal parametrizada para rastrear y extraer perfiles oficiales de redes sociales (LinkedIn, Facebook, Instagram, Twitter/X) de cualquier empresa o ejecutivo.

## ⚡ Flujo de Ejecución

```bash
python C:\Users\Antonio\.gemini\config\skills\social-media-scraping\scripts\run_social_media_scraping.py --target "Nombre Empresa" --domain "empresa.com" --platform all
```

## 📋 Parámetros
* `--target`: Nombre de la empresa o directivo objetivo.
* `--domain`: Dominio web institucional.
* `--platform`: Plataforma objetivo (`all`, `linkedin`, `facebook`, `twitter`, `instagram`).
