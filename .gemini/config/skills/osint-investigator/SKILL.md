# 🕵️ OSINT Investigator (Skill Agnóstica Universal)

## Visión General
Skill agnóstica universal parametrizada para perfilar decisores, directivos, CEOs y empresas objetivo mediante huellas digitales en fuentes abiertas (LinkedIn, registros comerciales, dorks).

## ⚡ Flujo de Ejecución

```bash
python C:\Users\Antonio\.gemini\config\skills\osint-investigator\scripts\run_osint_investigator.py --target "Nombre o Empresa" --domain "empresa.com"
```

## 📋 Parámetros
* `--target`: Nombre de la persona, permisionario o empresa.
* `--domain`: Dominio web institucional asociado.
