# Skill: Free Tier & Cloud Infra Optimizer

## Propósito
Optimizar costos de infraestructura para MVPs, prototipos y plataformas en producción aprovechando capas gratuitas (free tiers) y servicios auto-hospedados de proveedores como Vercel, Render, Supabase, Neon, Cloudflare, Firebase y Fly.io.

## Estrategias de Optimización
1. **Hosting & Serverless PaaS:**
   - Selección entre Vercel/Netlify (frontends/Next.js) y Render/Fly.io/Cloud Run (backends Docker/FastAPI/Node).
2. **Bases de Datos Gratuitas:**
   - Aprovechamiento de Supabase, Neon (Postgres serverless), PlanetScale, MongoDB Atlas y Firebase Firestore dentro de sus límites sin costo.
3. **Edge Functions & CDN:**
   - Uso de Cloudflare Workers / Pages para proxies de baja latencia y compresión de tráfico.
