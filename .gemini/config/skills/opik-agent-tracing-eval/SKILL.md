# Skill: Opik Agent Tracing & Evaluation

## Propósito
Implementar trazabilidad completa (observabilidad), monitoreo en tiempo real y frameworks de evaluación continua para pipelines de LLMs, agentes y sistemas RAG utilizando **Opik** de Comet ML.

## Funcionalidades
1. **Trazado Multi-Paso (Multi-step Tracing):**
   - Captura y visualización de cada llamada a LLMs, ejecuciones de herramientas/MCPs y pasos de recuperación RAG.
2. **Evaluación Continua & LLM-as-a-Judge:**
   - Datasets de prueba, experimentos comparativos y evaluación automatizada de hallazgos (hallucinaciones, relevancia, fidelidad del contexto).
3. **Integración Estándar OpenTelemetry:**
   - Compatibilidad con OpenAI, LangChain, CrewAI, DSPy y agentes locales.
