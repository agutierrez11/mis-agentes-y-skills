# ✍️ B2B Copywriting Frameworks (Skill Agnóstica Universal)

## Visión General
Skill agnóstica universal para redactar secuencias de prospección, ganchos de ventas y manejo de objeciones B2B basados en los frameworks de Corey Haines (Marketingskills).

## ⚡ Flujo de Ejecución

```bash
python C:\Users\Antonio\.gemini\config\skills\b2b-copywriting-frameworks\scripts\generate_b2b_copy.py --product "PayMind" --persona "Gasolineras Independientes" --pain "mermas de efectivo" --solution "Quioscos de Autocobro"
```

## 📋 Parámetros
* `--product`: Nombre de la solución o producto.
* `--persona`: Perfil de cliente ideal.
* `--pain`: Dolor o problema principal.
* `--solution`: Mecanismo de resolución.
