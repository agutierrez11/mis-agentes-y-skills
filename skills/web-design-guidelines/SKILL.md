# Web Interface Guidelines (Vercel Standards)

Enforce clean, high-performance web interface standards.

## Principles:
1. **Accessibility (WCAG AA/AAA):** High contrast ratio between text and background surfaces.
2. **Visual Hierarchy:** Distinct font size scales, line heights, and padding.
3. **Keyboard & Touch Targets:** Accessible interactive elements with clear hover and focus outlines.
4. **Clean DOM & Semantic HTML:** No redundant wrapper divs; clean semantic layout.
