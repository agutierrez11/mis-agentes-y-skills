# Skill: AG-UI & Generative UI Copilot

## Propósito
Diseñar e implementar copilotos de IA interactivos en aplicaciones web (Next.js / React) utilizando el protocolo AG-UI y componentes de Generative UI donde el agente puede renderizar componentes vivos, modificar la interfaz del usuario y gestionar colaboraciones humano-agente.

## Pilares de Implementación
1. **Protocolo AG-UI (Agent-User Interaction):**
   - Estado compartido síncrono entre el frontend y los endpoints agénticos (LangGraph, Mastra, PydanticAI o custom Node/Python backends).
2. **Generative UI & Human-in-the-Loop:**
   - Permite al agente renderizar modales de confirmación, tarjetas interactivas de prospectos, gráficos de ventas y formularios dinámicos directamente en el DOM.
3. **Persistencia & Auditable State:**
   - Almacenamiento estructurado de las sesiones del copiloto y registro auditable de acciones realizadas.

## Guía de Estilo UI
- Tema oscuro elegante por defecto, tipografías Google Fonts (Outfit / JetBrains Mono) y animaciones de transición fluidas.
