# UI UX Pro Max - Design System Knowledge Base

Provides rule-based design intelligence to build enterprise-grade software interfaces.

## Rules:
1. **Strict Spacing Grid:** 4px/8px/12px/16px/24px padding and gap alignment.
2. **Cohesive Badge System:** Status indicators (🟢 Vigente, 🟡 Probable, 🔍 Por Corroborar) with distinct background alpha channels and borders.
3. **Data Density:** High-density data tables with sticky headers, clear sort arrows, and hover feedback.
