# Frontend Design & Bespoke UI Engineering

Approach UI design as a design lead committed to distinctive visual identity. Reject templated AI defaults.

## Key Principles:
1. **Grounded Subject & Thesis:** Hero section and UI layout must encode the product's core subject (Sales Intelligence, BYOD Vaults).
2. **Typography Pairings:** Pair display faces (e.g. `Outfit`) and data faces (`JetBrains Mono`) with deliberate weights and letter-spacing.
3. **Opinionated Palettes:** Use curated HSL color tokens (Slate 950 base, Indigo/Violet glow accents) instead of plain browser defaults.
4. **Purposeful Structure:** Use glassmorphism, subtle borders, and intentional card groupings.
